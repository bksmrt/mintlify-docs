Proof has API connectors for several SIS vendors, but a college cannot connect any of them today. The only feed a college can connect is the [SFTP / CSV Drop](/sis/sftp-csv), which works with any SIS that can export CSV files.

| Vendor | Status | What it means |
| --- | --- | --- |
| Ellucian Banner | Beta | Built against the Ellucian Ethos REST API, not yet run against a live sandbox. Not offered to colleges. |
| Ellucian Colleague | Beta | Built against the Colleague Web API, not yet run against a live instance. Not offered to colleges. |
| Workday Student | Beta | Built against the Workday Student REST API, not yet run against a live tenant. Not offered to colleges. |
| Oracle PeopleSoft Campus Solutions | Coming soon | A placeholder. It cannot run syncs. |
| Jenzabar One | Coming soon | A placeholder. It cannot run syncs. |

The **Student records** section in **Settings › Integrations** does not offer a vendor picker. A request to connect or test any vendor other than the CSV feed is refused with `vendor_not_offered`: "`<vendor>` is not offered to colleges yet. Connect the registrar's CSV drop instead."

## What the beta connectors read

For reference, each beta connector reads the same five record types as the CSV feed, from these vendor resources:

| Record type | Banner (Ethos) | Colleague | Workday Student |
| --- | --- | --- | --- |
| Courses | `courses` | `courses` | `courseDefinitions` |
| Departments | `academic-departments` | `departments` | `academicDepartments` |
| Programs | `academic-programs` | `programs` | `programsOfStudy` |
| Terms | `academic-periods` | `terms` | `academicPeriods` |
| Faculty | `faculty` | `faculty` | `instructors` |

## Using a vendor's export today

If your SIS is Banner, Colleague, Workday, PeopleSoft, or Jenzabar, export courses, departments, programs, terms, and faculty to CSV on a schedule and write them to an SFTP folder Proof can reach. Then connect that folder as described in [SFTP and CSV drop](/sis/sftp-csv).
