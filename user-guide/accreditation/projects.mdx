A project is where Proof organizes a piece of work from start to finish, such as an accreditation review, a compliance response, or a curriculum change. Accreditation liaisons, compliance officers, and committee members use projects to see what is due, who owns it, and what is blocking progress.

Open **Projects** in the sidebar to see the project list. Select a project to open its detail page.

## What you see

### Project list

The list shows every project you can access. Switch between three views:

| View | Best for |
| --- | --- |
| **Cards** | Scanning projects at a glance |
| **Table** | Sorting and comparing many projects |
| **Timeline** | Seeing due dates and overlap across projects |

Narrow the list with **Quick Filters** and the **Project Filters** panel:

- **Status**: **Planning**, **In Progress**, **Under Review**, **On Hold**, **On Deck (Scheduled)**, **Completed**, **Cancelled**, **Archived**
- **Project Type**: **Compliance**, **Curriculum**, **Faculty**, **Scheduling**, **General**
- **Priority**: **Critical**, **High**, **Medium**, **Low**
- **Institution** and level

Use **Sort By** to order by **Name**, **Due Date**, **Priority**, **Progress**, and more. Each project also shows a standing, such as **On track**, **Attention**, **Blocked**, **Not started**, or **Done**.

### Project detail

The top of a project shows its progress and committee, plus a primary action for the next step. The tabs below depend on the project:

| Tab | What it shows |
| --- | --- |
| **My Role** | Your assignments on this project (only if you have a role) |
| **Overview** | Summary, current phase, impact, and quick actions |
| **Related** | Linked records, when any exist |
| **Timeline** | The project's schedule, when it follows a scenario |
| **Subprojects** | Child projects rolled up into this one |
| **Tasks** | Phases and the tasks inside each phase |
| **Committee** | Committee members and their roles |
| **Policies** | Policies this project touches |
| **Deliverables** | Outputs the project produces and their review |
| **Evidence** | Compliance gaps and curated evidence |
| **History** | Everything that has happened on the project |
| **Review Settings** | Review options for engagement projects (owners, leads, and admins) |

The **Actions** menu groups less common actions:

- **Project**: **Project overview**, **Compliance workspace**
- **Structure**: **Link projects…**, **Manage committee members…**, **Change governance style…**, **Save phases as template…**
- **Roll-up**: **Attach to a parent…**, **Add a subproject…**, **Move to another parent…**, **Detach from parent**
- **Lifecycle**: **Cancel project…**, **Reopen project…**, **Rewind to an earlier phase…**, **Transfer ownership…**, **Delete project…**

## What you can do here

- Create a project with **Enter a Project**. See [Start an accreditation project](/user-guide/accreditation/how-to/start-a-project).
- Open the [Compliance workspace](/user-guide/accreditation/compliance-workspace) to work through standards. See [Work a standard and close gaps](/user-guide/accreditation/how-to/work-a-standard).
- Review gaps and evidence on the **Evidence** tab. See [Add evidence and match it to standards](/user-guide/accreditation/how-to/add-and-match-evidence).
- Build the narrative for your accreditor. See [Prepare the self-study](/user-guide/accreditation/how-to/prepare-self-study).
- Clone a project to reuse its setup, or archive it when the work is done.
