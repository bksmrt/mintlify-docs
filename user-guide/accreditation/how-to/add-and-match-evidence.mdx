Evidence is what proves your narrative. This guide shows how to get documents into Proof, from a manual record, a cloud drive, or a request to colleagues, and then link them to the standards they support.

## Before you start

- You need a project with standards. See [Start an accreditation project](/user-guide/accreditation/how-to/start-a-project).
- To import from Google Drive, OneDrive, SharePoint, Box, or Dropbox, connect a storage account first. See [Document storage overview](/storage/overview).
- Uploading and linking evidence requires a role with evidence write access.

## Steps

<Steps>
  <Step title="Add documents to the register">
    Open [Documents](/user-guide/accreditation/documents) and select **Enter a Record** to add a policy, handbook, or other record directly.
  </Step>
  <Step title="Or import files from cloud storage">
    Open the project from [Projects](/user-guide/accreditation/projects) and go to the **Evidence** tab. Select **Import from cloud**, choose a connected account, browse to a file, and select **Import**. Imported files go into the evidence library and are matched against compliance standards automatically. Files marked **Unsupported** cannot be imported.
  </Step>
  <Step title="Request evidence you do not have yet">
    On the **Evidence** tab, choose the standards from **Select standards** and select **Request evidence** to ask colleagues for the missing documents.
  </Step>
  <Step title="Scan for matches">
    Open the [Compliance workspace](/user-guide/accreditation/compliance-workspace). From the **Actions** menu, select **Scan evidence** to look for supporting documents across every standard.
  </Step>
  <Step title="Confirm matches for each standard">
    Open a standard and review its evidence slots. Use **Find evidence** on an issue such as **Evidence needed** or **Unsupported claim**, then select **Confirm** on the right document to link it.
  </Step>
</Steps>

## What happens next

- Linked documents count toward the standard's evidence coverage, and related issues can be resolved.
- Firm consultants who confirm a match propose the document for the slot rather than linking it directly.
- If a cloud import fails, see [Document storage troubleshooting](/storage/troubleshooting).
