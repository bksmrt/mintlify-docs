The **Ask or find** box searches every part of the college's record from any page. Type a record's name to find it, or type a question to get an answer from Proof's reports.

## How to get here

- Press **⌘K** on a Mac or **Ctrl+K** on Windows, from any page.
- Or click the magnifying glass in the header.

Press **Esc** to close the box.

## What you see

Before you type, the box shows your **Recent** searches: the last three lines you sent. Proof keeps them with your account, so they follow you to another browser. Remove one with its **X**, or click **Clear** to remove them all.

After you send a line, the box shows the records that match it. The closest hits come first under **Best matches**, then the hits grouped by kind: people, projects, tasks, policies, compliance rules, documents, departments, courses, programs, and regulatory changes. You only see records your role lets you read.

The footer tells you what the send key will do next, for example **asks**, **shows the results**, or **opens** followed by a record's name.

## Find a record

1. Type the record's name, for example a course code such as `NURS 3310`.
2. Press **Ctrl+Enter** (**⌘+Enter** on a Mac), or click the arrow button. Proof shows the matching records.
3. Send again to open the first record. To open a different one, press **↓** to move to it, then press **Enter**.

If no record matches, Proof asks the line as a question instead.

## Ask a question

Proof treats a line as a question when it ends with `?` or starts with a word such as *what*, *which*, *who*, *how*, *show*, or *list*. For example: `who owns the BSBA core update?`

When you send a question, Proof answers it in the box with the same answer card you get in [Report Studio](/user-guide/reports/report-studio):

- Records the question names appear above the answer under **Records it names**. Click one to open it.
- To find a policy or document by what it covers, ask for it without its name, for example `do we have a policy on faculty workload?`. Proof searches the policies and documents you may read and lists the ones that fit under **Records it found**. Each shows the passage that matched. Click a title to open the record.
- Click a suggested follow-up, or type one in **Ask a follow-up…**, to keep going.
- When the answer is a report, click **Edit** to open it in Report Studio and refine it there.
- If Proof could not answer, the card says why. Click **Retry** to ask again.

Closing the box clears the answer.

## Run a command

Type `/` to list the commands. Pick one with the arrow keys and press **Enter**, or click it.

**Narrow the search to one kind of record:**

| Command | Searches |
| --- | --- |
| `/users` | Users only |
| `/projects` | Projects only |
| `/tasks` | Tasks only |
| `/policies` | Policies only |
| `/rules` | Compliance rules only |
| `/documents` | Documents only |
| `/courses` | Courses only |
| `/programs` | Academic programs only |
| `/departments` | Academic departments only |
| `/changes` | Regulatory changes only |

**Narrow projects and tasks by owner or status:**

| Command | Shows |
| --- | --- |
| `/my` | Your projects and tasks |
| `/active` | Projects and tasks in progress or in review |
| `/pending` | Projects and tasks not yet started or on hold |
| `/completed` | Projects and tasks completed or approved |

An active filter appears under the line after **Showing only**. Click it to remove it.

**Go somewhere or create something:**

| Command | Does |
| --- | --- |
| `/create section` | Plans a new course section draft. Choose the course and the term, then send to create the draft. |
| `/create project` | Opens the page for creating a new project. |
| `/go dashboard` | Goes to the dashboard. |
| `/go settings` | Goes to settings. |
| `/go compliance` | Goes to compliance. |

## Keys in the box

| Key | Does |
| --- | --- |
| **Ctrl+Enter** (**⌘+Enter** on a Mac) | Sends the line: shows the results, opens the first record, asks the question, or runs the command |
| **Enter** | Adds a new line, or opens the record or command you moved to with **↓** |
| **↓** / **↑** | Moves through the list |
| **Esc** | Closes the box |

<Note>
The same rule applies across Proof. In fields where you write text, such as a comment, a reply, or the Report Studio chat, **Enter** adds a new line and **Ctrl+Enter** (**⌘+Enter** on a Mac) sends. In forms with several fields, **Enter** no longer submits the form; use **Ctrl+Enter** or click the form's button.
</Note>
